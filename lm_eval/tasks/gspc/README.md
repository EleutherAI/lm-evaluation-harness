# GSPC — Governance · Safety · Provenance · Continuity benchmark suite

13-axis AI governance & safety measurement tasks published by CSOAI (Council for the Safety of Artificial Intelligence).

- Banks: CC-BY-4.0, publicly loadable from the Hugging Face Hub (`csoai/gspc-*`), each with a per-bank SHA-256 and contamination canary GUID in the task metadata.
- Group: `gspc` (aggregate exact_match). Individual: `gspc_governance`, `gspc_care`, `gspc_safety`, `gspc_detector_interop`, `gspc_affect`, `gspc_provenance`, `gspc_cross_reality`, `gspc_machinery`, `gspc_openness`, `gspc_continuity`, `gspc_swarm`, `gspc_conformance`, `gspc_art5_safeguard`.
- Full suite repo with runbook + verified reproduction row: https://github.com/CSOAI-ORG/gspc-benchmark
- Live signed measurement board these banks feed: https://councilof.ai/api/gspc
- Note: `gspc_swarm` is a retired single-label bank retained for provenance; exclude from interpretation.

Measurement, not certification.
